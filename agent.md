Контекст:
Telegram Mini App для курьеров — учёт смен, статистика заработка, тарифы,
профиль. Работает внутри Telegram (WebApp API), в шапке — системная
панель Telegram ("Закрыть", стрелка вниз, "..."). Нижняя навигация:
Расчёт / Статистика / Рейтинг / Профиль.

Общее направление стиля:
Нейтральный корпоративный стиль, как в банковских приложениях
(Тинькофф/Т-Банк, Сбер, Revolut) — чистый, строгий, вызывающий доверие
к цифрам и деньгам. Никакой "курьерской" яркости и хаотичных ярких
акцентов (сейчас в статистике одновременно жёлтый, зелёный, фиолетовый,
оранжевый без единой логики — это выглядит несобранно). Один основной
цвет бренда + 1-2 семантических цвета (доход/расход, рост/падение) —
и всё.

Обязательно учесть, что это Telegram Mini App:
- Использовать Telegram theme params (bg_color, text_color, hint_color,
  link_color, button_color, secondary_bg_color) через
  window.Telegram.WebApp.themeParams вместо хардкода цветов, чтобы
  приложение подстраивалось под тему пользователя (светлая/тёмная,
  кастомные темы Telegram).
- Использовать нативные MainButton/BackButton Telegram WebApp API вместо
  кастомных кнопок там, где это уместно (например, "Рассчитать" —
  кандидат на MainButton).
- Учитывать safe area и системную шапку Telegram — контент экрана НЕ
  должен начинаться сразу под системной панелью и тем более наезжать
  на неё (см. баги ниже).
- Поддержать haptic feedback (Telegram.WebApp.HapticFeedback) на ключевых
  действиях: степпер, переключение вкладок, нажатие "Рассчитать".

КОНКРЕТНЫЕ БАГИ, которые нужно исправить (видны на скриншотах):
1. На экране "Статистика" заголовок "Статистика" наезжает на системную
   панель Telegram сверху — нет отступа/safe-area сверху экрана.
2. При скролле длинного списка смен заголовки блоков ("Статистика",
   графики) наезжают на липкую панель "Закрыть" — нужна прозрачная/цельная
   шапка приложения со своим z-index и отступом, а не наложение.
3. Тултип графика "Доход за период" (при тапе на точку) выезжает за
   пределы графика и перекрывает заголовок блока — нужно позиционировать
   тултип внутри границ графика или показывать значение снизу/сбоку.
4. Числа с "фальшивой точностью": "Доход/час: 526,815 ₽",
   "Доход/км: 75,24 ₽" — это выглядит как баг форматирования (слишком много
   знаков после запятой для рублей). Все денежные значения округлять до
   целых рублей (или до 2 знаков только где это осмысленно, например тариф
   "0.54 ₽/мин").
5. В блоке "Итого за период" (Расчёт) показаны "Доход с налогом" красным
   и "Доход (чистый)" зелёным без объяснения — нужно подписать явно,
   что означает каждое число (например через (i) с пояснением при тапе).
6. Плейсхолдер "82" в поле "Километраж" на первом экране визуально не
   отличим от введённого значения — нужно явно различать placeholder
   (пример) и реальные данные.

Задачи по UX/UI дизайну (в стиле банковского приложения):

Общая система:
- Единая цветовая палитра: 1 основной акцент (для CTA, активных вкладок,
  ссылок), 1 цвет для "рост/доход" (обычно зелёный), 1 цвет для
  "расход/налог/предупреждение" (обычно красный или оранжевый), остальное —
  оттенки серого/нейтрального фона. Предложи 5-6 конкретных hex-значений.
- Единая типографика: чёткая иерархия — крупные суммы (табличные цифры,
  моноширинные для чисел, чтобы не "прыгали"), заголовки экранов, лейблы
  полей, вспомогательный текст. Один шрифт с несколькими начертаниями,
  без декоративных шрифтов.
- Единый стиль карточек: одинаковые скругления, тени/бордеры, отступы
  между карточками по всему приложению (сейчас где-то карточки с рамкой,
  где-то с цветной заливкой без системы).
- Светлая и тёмная тема, синхронизированные с Telegram theme.

Экран "Расчёт" (главный):
- Живой предпросчёт суммы по мере ввода данных.
- Понятный степпер часов/минут с крупными тач-таргетами.
- Явный переключатель "по зонам / вместе" (segmented control), а не мелкая
  ссылка.
- MainButton Telegram вместо кастомной кнопки "Рассчитать".

Экран "Статистика":
- Календарь-теплокарта: сделать легенду компактнее и разместить сразу под
  календарём без лишнего скролла; цвета теплокарты — оттенки одного
  акцентного цвета по интенсивности (сейчас жёлтый/зелёный вперемешку
  читается как разные категории, а не шкала).
  Например: 4 оттенка одного синего/зелёного от бледного к насыщенному.
- Карточки "Доход/час" и "Доход/км" — привести к единому нейтральному
  стилю карточек, а не разноцветным фиолетовому/оранжевому блокам.
  Выделять цветом можно только знак изменения (рост/падение к прошлому
  периоду), а не сам факт наличия метрики.
- Список смен — единый компактный формат карточки: дата, длительность,
  заказы, км слева; сумма справа крупным моноширинным шрифтом.
- Графики (доход, километраж): убрать заезжающие тултипы, подписи осей
  сделать читаемыми, добавить сглаживание/явное указание пропусков данных
  (дни без смен).

Экран "Профиль":
- Разделить визуально блоки "Профиль", "Тарифы", "Параметры" явными
  заголовками секций с отступами, сейчас граница между блоками едва
  заметна.
- Тарифы по зонам — свести в единую таблицу/список вместо трёх колонок
  вперемешку с "За минуту".
- Чекбокс "Учитывать бензин" — сделать полноценным toggle-переключателем
  (как везде в банковских/системных настройках), а не квадратным чекбоксом.

Нижняя навигация:
- Чётче выделять активную вкладку (сейчас разница между активной "Статистика"
  и неактивными пунктами почти не считывается — слабый контраст).

Технические ограничения:
- Next.js + Tailwind CSS.
- Telegram WebApp SDK (@twa-dev/sdk или аналог) для themeParams,
  MainButton/BackButton, HapticFeedback.
- Доступность: видимый фокус, контраст текста AA минимум, поддержка
  reduced motion.
- Не использовать <form> с submit по умолчанию.
